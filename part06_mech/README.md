# Part 6. 밸런싱로봇 기구 설계 with Fusion360

이 파트에서는 밸런싱 로봇의 몸체를 직접 설계합니다. 플레이트 3장(하판, 중판, 상판)과 모터 브래킷 1종을 Autodesk Fusion(옛 이름 Fusion 360)으로 모델링하고, 도면을 만들고, 조립해서 간섭을 확인한 뒤 STL로 내보내 3D 프린터로 출력합니다.

같은 부품을 Python 스크립트로도 만들 수 있게 준비했습니다. Fusion에서 만든 모델과 스크립트가 만든 STL을 비교하면 내 치수가 맞는지 바로 확인할 수 있고, 치수를 바꿔야 할 때 스크립트로 빠르게 다시 만들 수 있습니다.

이 파트에서 쓰는 기준 치수는 공통 사양서(SPEC.md) 5장을 그대로 따릅니다.

| 항목 | 값 |
|---|---|
| 플레이트 | 120 x 75 x 4 mm, 3장, 모서리 R4 |
| 모서리 홀 | M4 관통 Ø4.4, 가장자리에서 6 mm 안쪽 (홀 간격 108 x 63) |
| 층간 서포트 | M4 x 50 mm |
| 일반 M3 홀 | Ø3.4 |
| 모터 | 25 mm 기어드 DC 모터, 축 4 mm, 2개 |
| 바퀴 | 지름 130 mm |
| L298N 장착 홀 | 37 x 37 mm, M3 |
| Uno 장착 홀 (보드 기준) | (13.97, 2.54), (15.24, 50.80), (66.04, 7.62), (66.04, 35.56) |

결과물 폴더 구성은 다음과 같습니다.

| 경로 | 내용 |
|---|---|
| `part06_mech/cad/generate.py` | 파라메트릭 생성 스크립트 |
| `part06_mech/stl/` | plate_bottom, plate_middle, plate_top, motor_bracket STL |
| `part06_mech/dxf/` | 레이저 커팅용 플레이트 외곽선 DXF |
| `part06_mech/img/` | 2D 치수 도면과 조립 미리보기 그림 |
