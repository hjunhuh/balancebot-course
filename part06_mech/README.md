# Part 6. 밸런싱로봇 기구 설계 with Fusion360

이 파트에서는 밸런싱 로봇의 몸체를 직접 설계합니다. 플레이트 3장(하판, 중판, 상판)과 모터 브래킷 1종을 Autodesk Fusion(옛 이름 Fusion 360)으로 모델링하고, 도면을 만들고, 조립해서 간섭을 확인한 뒤 STL로 내보내 3D 프린터로 출력합니다.

같은 부품을 Python 스크립트로도 만들 수 있게 준비했습니다. Fusion에서 만든 모델과 스크립트가 만든 STL을 비교하면 내 치수가 맞는지 바로 확인할 수 있고, 치수를 바꿔야 할 때 스크립트로 빠르게 다시 만들 수 있습니다.

## 6-01 기구 설계가 제어에 미치는 영향

밸런싱 로봇은 바퀴 축을 받침점으로 하는 역진자(거꾸로 선 진자)입니다. 펌웨어(Part 8)에서 PID 게인을 아무리 잘 맞춰도 기구가 제어하기 어려운 모양이면 서 있지 못합니다. 설계를 시작하기 전에 네 가지 요소가 제어에 어떤 영향을 주는지 정리합니다.

![조립 미리보기와 무게중심](part06_mech/img/assembly_preview.png)

### 무게중심 높이 L

축에서 무게중심까지 거리를 L이라고 하면, 기울기 θ가 작을 때 몸체의 운동 방정식은 다음과 같습니다.

```
I * θ'' = m * g * L * θ      (I: 축 기준 관성 모멘트, m: 몸체 질량)
θ(t) = θ0 * e^(t / τ),       τ = sqrt( I / (m * g * L) )
```

τ(타우)는 넘어지는 속도를 나타내는 시간 상수입니다. 기울기가 τ마다 약 2.7배씩 커집니다. 질량이 한 점에 모여 있다고 보면 I = m L² 이므로 τ = sqrt(L / g) 가 되어, **무게중심이 높을수록 τ가 커지고 천천히 넘어집니다**. 빗자루를 손바닥에 세울 때 긴 빗자루가 더 쉬운 것과 같은 원리입니다.

생성 스크립트는 부품 질량 추정값으로 이 값을 직접 계산합니다.

| 배치 | 몸체 질량 | L | τ | 1도에서 20도까지 넘어지는 시간 (약 3τ) |
|---|---|---|---|---|
| 배터리를 상판에 둠 (이 과정의 설계) | 630 g | 69.3 mm | 112 ms | 약 336 ms |
| 배터리를 하판에 둔다고 가정 | 630 g | 32.7 mm | 85 ms | 약 255 ms |

제어 주기가 5 ms(SPEC 3장)이므로 τ = 112 ms 동안 제어기는 22번 모터 출력을 고칠 수 있습니다. 배터리 4개(약 210 g)를 상판에 올린 이유가 이것입니다. 다만 너무 높이면 같은 각도를 되돌리는 데 필요한 바퀴 이동 거리가 길어지고 몸체가 커져 다루기 불편하므로, 이 과정은 층간 50 mm 서포트로 적당한 높이를 정했습니다.

### 관성 모멘트 I

같은 질량과 같은 L이라도 질량이 위아래로 넓게 퍼져 있으면 I가 커져 τ가 조금 더 커집니다. 반대로 앞뒤(Y 방향)로 무거운 부품이 치우치면 무게중심이 축 바로 위에 오지 않습니다. 이 설계는 모든 부품을 플레이트 중심선(Y = 37.5 mm)에 맞춰 배치했습니다.

### 바퀴 지름

바퀴 지름 D와 모터 회전수 n(rpm)으로 바퀴 속도는 v = π D n / 60 입니다. 130 mm 바퀴는 한 바퀴에 약 408 mm를 갑니다. 지름이 크면 같은 모터로 더 빨리 몸체 밑으로 바퀴를 보낼 수 있지만, 바닥을 미는 힘은 F = 토크 / 반지름 이므로 줄어듭니다.

필요한 토크를 대략 계산해 봅니다. 기울기 5도를 되돌리려면 바퀴가 약 a = g tan(5도) = 0.86 m/s² 로 가속해야 합니다. 바퀴를 포함한 전체 질량을 0.73 kg 으로 보면 모터 한 개가 내야 하는 토크는 0.73 x 0.86 x 0.065 / 2 = 약 0.020 Nm (약 0.2 kgf cm) 입니다. 25 mm 기어드 모터는 감속비에 따라 정격 토크가 0.5 kgf cm 이상이므로 여유가 있습니다.

바퀴 지름은 축 높이(지면에서 65 mm)도 정합니다. 바퀴가 크면 몸체 전체가 올라가고, 넘어졌을 때 몸체가 바닥에 닿기 전 바퀴가 버텨 주는 범위도 넓어집니다. 스크립트 검사 결과 이 설계는 몸체를 100도 넘게 기울여야 바퀴 말고 다른 곳이 바닥에 닿습니다.

### 축 위치

바퀴 축은 무게중심의 바로 아래(앞뒤 방향 가운데)에 있어야 합니다. 무게중심이 축에서 앞뒤로 d 만큼 어긋나면 로봇이 서 있는 각도가 atan(d / L) 만큼 기웁니다. 예를 들어 d = 3 mm, L = 69 mm 이면 약 2.5도입니다. 이 차이는 블루투스 명령 `$T` (기준 각도 보정, SPEC 4장)로 보정할 수 있지만, 처음부터 대칭으로 만드는 것이 좋습니다. 또한 모터 축은 하판 아랫면에서 16.6 mm 아래에 두어, 무거운 모터(2개 약 190 g)가 축 근처에 모이게 했습니다.

## 6-02 Fusion360 설치(개인용 무료 라이선스)와 화면 구성, 단위 mm 설정

### 설치와 개인용 라이선스

Autodesk Fusion은 수익이 거의 없는 개인 취미 용도라면 "Fusion for personal use" 라이선스로 무료로 쓸 수 있습니다.

1. Autodesk 웹사이트에서 "Fusion for personal use" 페이지로 갑니다.
2. Autodesk 계정을 만들고 개인용 라이선스 조건(비상업, 프로젝트 수익 연 1,000 달러 미만)에 동의합니다.
3. 설치 프로그램(Windows, macOS)을 내려받아 실행하고 같은 계정으로 로그인합니다.

개인용 라이선스에는 제한이 있고 Autodesk가 조건을 바꾸기도 하므로 설치할 때 공식 페이지를 다시 확인합니다. 이 과정과 관련된 제한은 다음과 같습니다 (작성 시점 기준).

| 제한 | 이 과정에서의 대응 |
|---|---|
| 편집 가능한 활성 문서 10개 | 로봇 전체를 문서 1개 안의 컴포넌트 여러 개로 만듭니다 (부품마다 문서를 따로 만들지 않습니다) |
| 내보내기 형식 제한 (STL, STEP, 3MF 등은 가능) | STL은 Fusion에서 내보내고, 레이저 커팅용 DXF는 생성 스크립트가 만든 `part06_mech/dxf/` 를 씁니다 |
| 도면(Drawing)은 시트 1장, 내보내기 제한 | 부품마다 시트 1장으로 만들고 인쇄 기능으로 출력합니다 |
| 라이선스 기간 | 기간이 끝나면 계정 페이지에서 갱신합니다 |

### 화면 구성

처음 실행해서 새 디자인을 열면 다음 영역이 보입니다.

| 영역 | 위치 | 역할 |

### 단위 mm와 Z 위쪽 설정

1. 오른쪽 위 계정 이름을 눌러 Preferences 를 엽니다.
2. General > Design 에서 Default modeling orientation 을 **Z up** 으로 바꿉니다. 이 과정의 좌표(X 길이, Y 폭, Z 높이)와 생성 스크립트가 이 방향을 씁니다.
3. Unit and Value Display (또는 Default Units > Design) 에서 Default units 를 **Millimeter** 로 바꿉니다.
4. 이미 열려 있는 문서는 브라우저 맨 위 문서 이름 아래 Document Settings > Units 의 연필 아이콘을 눌러 Millimeter 로 바꿉니다.
5. 데이터 패널에서 New Project 로 `balancebot` 프로젝트를 만들고, 새 디자인을 `balancebot_mech` 이름으로 저장합니다(Ctrl + S).

## 6-03 스케치 기본 (선, 사각형, 원, 구속조건, 치수 구속, 완전 구속 확인)

3D 모델은 대부분 2D 스케치에서 시작합니다. 스케치를 정확히 "구속"하는 습관이 기구 설계의 기본입니다.

### 스케치 만들기

1. SOLID 탭 > CREATE > Create Sketch 를 누릅니다.
2. 캔버스에 나타난 세 평면 중 XY 평면(바닥에 누운 평면)을 클릭합니다.
3. 툴바가 SKETCH 탭으로 바뀝니다. 끝낼 때는 오른쪽 위 Finish Sketch 를 누릅니다.

### 기본 도형

| 도구 | 단축키 | 사용법 |
|---|---|---|
| Line | L | 클릭, 클릭으로 선분. 클릭 후 드래그하면 접하는 호 |
| 2-Point Rectangle | R | 대각선 두 점. 클릭 후 숫자 입력, Tab 으로 다음 칸 |
| Center Rectangle | | 중심과 한 꼭짓점 |
| Center Diameter Circle | C | 중심 클릭 후 지름 입력 |
| Center to Center Slot | | 두 중심점과 폭으로 긴 구멍 |
| Point | | 구멍 위치 표시용 점 |
| Construction (토글) | X | 선택한 선을 보조선(점선)으로 바꿈. 보조선은 형상을 만들지 않음 |

### 구속조건 (Constraints)

구속조건은 도형 사이의 관계를 고정합니다. SKETCH 탭 오른쪽 CONSTRAINTS 그룹에 있습니다.

| 구속 | 의미 | 이 과정에서 쓰는 곳 |
|---|---|---|
| Horizontal / Vertical | 수평, 수직 | 사각형 변 (자동으로 붙음) |
| Coincident | 점을 점이나 선 위에 붙임 | 사각형 꼭짓점을 원점에 |
| Concentric | 두 원의 중심 일치 | 홀과 서포트 |
| Midpoint | 점을 선의 중점에 | 플레이트 중심선 |
| Equal | 길이나 지름이 같게 | 같은 지름 홀 여러 개 |
| Symmetry | 선을 기준으로 대칭 | 좌우 슬롯, 브래킷 단면 |
| Fix | 위치를 고정 | 가능하면 쓰지 않고 치수로 고정 |

### 치수 구속 (Sketch Dimension, D)

`D` 를 누르고 선이나 두 점, 원을 차례로 클릭한 뒤 놓을 곳을 클릭하고 값을 입력합니다. 원을 클릭하면 지름 치수, 두 점을 클릭하면 거리 치수가 됩니다. 치수 값에 `plate_l / 2` 같은 식도 쓸 수 있습니다 (MODIFY > Change Parameters 에서 사용자 파라미터를 만들면 생성 스크립트처럼 이름으로 치수를 관리할 수 있습니다).

### 완전 구속 확인

- 아직 움직일 수 있는 선은 **파란색**, 완전히 고정된 선은 **검은색** 으로 보입니다.
- 브라우저의 스케치 아이콘에 자물쇠가 표시되면 그 스케치 전체가 완전 구속입니다.
- 파란 선을 마우스로 끌어 보면 어느 방향으로 자유도가 남았는지 알 수 있습니다.

완전 구속이 안 된 스케치는 나중에 다른 치수를 고칠 때 엉뚱하게 움직입니다. 각 스케치를 끝내기 전에 모든 선이 검은색인지 확인하는 습관을 들입니다.

## 6-04 Extrude, Hole, Fillet, Chamfer, Mirror, Pattern

이 과정의 부품은 여섯 가지 명령으로 거의 다 만들 수 있습니다.

| 명령 | 위치 (SOLID 탭) | 단축키 | 핵심 옵션 |
|---|---|---|---|
| Extrude | CREATE | E | Profile(닫힌 영역) 선택, Distance, Operation (New Body, Join, Cut, New Component) |
| Hole | CREATE | H | 위치(면 위 클릭 또는 스케치 점), Extents = All, Hole Type = Simple, Diameter |
| Fillet | MODIFY | F | 모서리 선택, Radius |
| Chamfer | MODIFY | | 모서리 선택, Distance |
| Mirror | CREATE | | Pattern Type (Faces, Features, Bodies), Mirror Plane |
| Rectangular Pattern | CREATE > Pattern | | 대상, 방향 2개, Quantity, Distance, Distribution (Spacing 은 간격, Extent 는 전체 길이) |
| Circular Pattern | CREATE > Pattern | | 대상, 축, Quantity |

알아 둘 점:

- **Extrude Cut 과 Hole 의 차이**: 원을 스케치해 Extrude Cut 해도 구멍이 생기지만, Hole 명령으로 만들면 도면에서 구멍 주석(지름, 관통)이 자동으로 붙고 나중에 볼트 규격으로 바꾸기 쉽습니다. 원형 관통홀은 Hole, 슬롯은 Extrude Cut 을 씁니다.
- **Extent = All**: 판 두께를 바꿔도 구멍이 끝까지 뚫리도록 깊이 대신 All(관통)을 고릅니다.
- **Pattern 대상 선택**: Features 로 패턴하면 원본 피처를 고쳤을 때 복사본도 같이 바뀝니다.
- **Mirror 평면**: 플레이트 중심을 지나는 평면이 필요하면 CONSTRUCT > Midplane 으로 양 끝면 사이 중간 평면을 만듭니다.
- **Fillet 과 Chamfer**: 플레이트 모서리 R4 는 Fillet 으로, 모터 구멍 입구처럼 끼워 넣는 곳은 Chamfer 0.5 mm 로 입구를 넓히면 조립이 쉽습니다.

![모터 브래킷 도면](part06_mech/img/drawing_bracket.png)

## 6-05 하판 모델링 따라하기 (단계별 클릭 순서와 수치)

하판은 모터 브래킷 2개(아랫면)와 L298N(윗면)을 받칩니다. 아래 도면의 좌표표를 옆에 띄워 두고 따라 합니다. 좌표 원점은 플레이트 왼쪽 아래 모서리입니다.

![하판 도면](part06_mech/img/drawing_bottom.png)

### 1단계: 컴포넌트 만들기

1. 브라우저 맨 위 문서 이름을 오른쪽 클릭 > New Component.
2. Name 에 `plate_bottom` 입력, OK.
3. 브라우저에서 `plate_bottom` 옆 라디오 버튼이 켜져 있는지(활성 컴포넌트) 확인합니다. 이후 만드는 스케치와 바디는 이 컴포넌트 안에 들어갑니다.

### 2단계: 외곽과 Extrude

1. Create Sketch > XY 평면.
2. 2-Point Rectangle(R): 원점 클릭, `120` 입력, Tab, `75` 입력, Enter.
3. 모든 선이 검은색인지 확인 (원점에 붙었으므로 완전 구속). Finish Sketch.
4. Extrude(E): 사각형 안쪽 클릭, Distance `4`, Operation New Body, OK.
5. Fillet(F): 판의 세로 모서리 4개(두께 방향 짧은 모서리)를 클릭, Radius `4`, OK.

### 3단계: 모서리 M4 홀 4개

1. Hole(H): 판 윗면을 클릭해 위치를 정합니다. 나타난 기준 핸들로 왼쪽 변과 아래 변을 차례로 클릭하고 각각 `6` 입력.
2. Extents `All`, Hole Type `Simple`, Diameter `4.4`, OK.
3. Rectangular Pattern: Pattern Type `Features`, Objects 에서 타임라인의 방금 만든 Hole 을 선택.
4. Directions 에서 판의 아래 긴 모서리 선택, Distribution `Spacing`, Quantity `2`, Distance `108`.
5. 두 번째 방향(Direction 2)으로 왼쪽 짧은 모서리 선택, Quantity `2`, Distance `63`. 화살표 방향이 판 안쪽을 향하는지 확인하고 OK.

### 4단계: 모터 브래킷 고정 M3 홀 4개 (B1 ~ B4)

1. 판 윗면에 Create Sketch.
2. Point 로 점 2개를 찍고 치수(D)로 B1 (15, 16.5), B2 (15, 58.5) 를 맞춥니다. 왼쪽 변에서 `15`, 아래 변에서 `16.5` 와 `58.5`.
3. Finish Sketch, Hole(H) 에서 Sketch Points 로 두 점을 고르고 Extents `All`, Diameter `3.4`.
4. Mirror: Pattern Type `Features`, 방금 Hole 선택, Mirror Plane 은 CONSTRUCT > Midplane 으로 왼쪽 끝면과 오른쪽 끝면 사이에 만든 평면(X = 60). B3 (105, 16.5), B4 (105, 58.5) 가 생깁니다.

간격 42 mm 는 브래킷 플랜지의 고정 홀 간격과 같아야 합니다. 브래킷 위치(X = 15)는 모터 기어박스 앞면이 플레이트 가장자리에서 2 mm 안쪽, 브래킷이 그 앞면에서 3 mm 떨어진 위치에서 계산된 값입니다 (브래킷 길이 20 mm 의 중심 = 2 + 3 + 10).

### 5단계: L298N M3 홀 4개 (C1 ~ C4)

1. Hole(H): 윗면을 클릭하고 기준 모서리에서 X `41.5`, Y `19` 를 입력, Diameter `3.4`, Extents `All`.
2. Rectangular Pattern: 방금 Hole, 방향 1 은 긴 모서리 Quantity `2` Distance `37`, 방향 2 는 짧은 모서리 Quantity `2` Distance `37`.
3. 결과 C1 (41.5, 19), C2 (78.5, 19), C3 (78.5, 56), C4 (41.5, 56). 37 x 37 정사각형의 중심이 판 중심 (60, 37.5) 과 같은지 확인합니다.

### 6단계: 모터 배선 슬롯 (S1, S2)

1. 판 윗면에 Create Sketch.
2. Center to Center Slot: 첫 중심 (33, 32.5), 둘째 중심 (33, 42.5), 폭 `6`. 결과 슬롯은 6 x 16 mm 입니다 (중심 간 거리 10 + 양 끝 반원 3 + 3).
3. 위 중심을 수평 중심선(Y = 37.5)에 대해 Symmetry 로 묶고, 왼쪽 변에서 `33` 치수를 주어 완전 구속합니다.
4. Finish Sketch, Extrude(E): 슬롯 안쪽 선택, Operation `Cut`, Extent `All`.
5. Mirror 로 S2 (87, 37.5) 를 만듭니다.

### 7단계: 확인

브라우저에서 바디를 오른쪽 클릭 > Properties 를 열어 Volume 이 약 **34,705 mm³ (34.7 cm³)** 인지 봅니다. 생성 스크립트가 계산한 이론 부피와 같으면 구멍 크기와 개수가 모두 맞은 것입니다.

## 6-06 중판

| U1 | (13.97, 2.54) | (39.68, 13.37) |
| U2 | (15.24, 50.80) | (40.95, 61.63) |
| U3 | (66.04, 7.62) | (91.75, 18.45) |
| U4 | (66.04, 35.56) | (91.75, 46.39) |

5. Hole(H): Sketch Points 로 4점 선택, Diameter `3.4`, Extents `All`.

Uno 의 USB 단자와 전원 잭은 보드 왼쪽(X 가 작은 쪽)에 있습니다. 보드 방향을 도면과 같게 놓으면 USB 단자가 S1 슬롯 쪽을 향하므로 케이블을 연결할 수 있습니다. U2 홀은 USB 단자 옆이라 볼트 머리가 단자에 닿을 수 있으니 나일론 볼트나 작은 머리 볼트를 씁니다.

## 6-08 모터 브래킷

25 mm 원형 기어드 모터를 감싸 쥐는 클램프 블록입니다. 위쪽 플랜지를 하판 아랫면에 M3 볼트 2개로 고정하고, 아래쪽 귀(ear)를 M3 볼트로 조여 모터를 잡습니다. 같은 부품 2개를 좌우에 씁니다.

![모터 브래킷 도면](part06_mech/img/drawing_bracket.png)

| 치수 | 값 | 이유 |
|---|---|---|
| 모터 구멍 | Ø25.2 | 모터 Ø25 + 여유 0.2. 슬릿을 조여 잡음 |
| 플랜지 | 51 x 5 | 고정 홀 간격 42 와 너트 자리 |
| 몸통 폭 | 34 | 구멍 양옆 벽 4.4 |
| 윗면에서 축까지 | 16.6 | 위 벽 4 + 반지름 12.6 |
| 전체 높이 | 40.7 | 아래 벽 2.5, 귀 높이 9 |
| 슬릿 | 2 | 조이면 구멍이 줄어 모터를 잡음 |
| 클램프 홀 | Ø3.4, 바닥에서 4.5 | M3 x 16 + 너트 (귀 폭 12 + 너트 2.4 = 14.4) |
| 길이 | 20 | 모터 축 방향 |

따라하기:

1. New Component `motor_bracket`.
2. YZ 평면(모터 축 X 에 수직인 평면)에 Create Sketch. 한 번에 단면 전체를 그립니다.
   1. Line 으로 위 표의 외곽(플랜지, 몸통, 귀)을 한 붓 그리기로 그립니다. 플랜지 윗면을 원점 높이에 두고, 세로 보조선(Construction) 하나를 원점에서 아래로 그려 대칭 기준으로 씁니다.
   2. 좌우 대응 선분을 Symmetry 로 묶은 뒤 치수 51, 5, 34, 40.7, 12 를 줍니다.
   3. Center Diameter Circle 로 구멍 Ø25.2, 중심을 대칭 보조선 위, 윗면에서 16.6 아래에 둡니다.
   4. 슬릿: 대칭 보조선 양쪽 1 mm 에 세로선 2개를 원 아래쪽부터 바닥까지 그리고 바닥 선을 Trim(T) 으로 잘라 냅니다.
   5. 모든 선이 검은색인지 확인하고 Finish Sketch.
3. Extrude(E): 원과 슬릿을 뺀 단면 영역 선택, Direction `Symmetric`, Distance `20` (전체 20). 단면이 YZ 평면 양쪽으로 10 mm 씩 나옵니다.
4. 플랜지 고정 홀: Hole(H), 플랜지 윗면, 대칭선에서 좌우 `21`, 길이 방향 가운데(`10`), Diameter `3.4`, Extents `All`.
5. 클램프 홀: Hole(H), 귀의 옆면을 클릭, 바닥에서 `4.5`, 길이 방향 가운데, Diameter `3.4`, Extents `All` (귀 두 개와 슬릿을 모두 관통).
6. 선택: Chamfer 0.5 mm 를 모터 구멍 양쪽 입구에 줍니다.

플랜지 고정 너트(M3, 대변 5.5 mm)는 플랜지 아랫면에서 몸통 옆에 놓입니다. 너트 중심이 대칭선에서 21 mm, 몸통 옆면이 17 mm 이므로 너트와 몸통 사이는 0.82 mm 입니다. 생성 스크립트가 이 값을 검사하며, 모터 지름이나 고정 홀 간격을 바꿀 때 가장 먼저 걸리는 항목입니다.
