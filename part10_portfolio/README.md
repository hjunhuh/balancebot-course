# Part 10. 취업을 위한 포트폴리오

이 과정의 산출물은 그대로 포트폴리오가 됩니다. 채용 담당자가 임베디드 포트폴리오에서 확인하고 싶은 것은 "무엇을 만들었나"보다 **"어떻게 판단하고 검증했나"** 입니다. 같은 밸런싱 로봇이라도 요구사항, 설계 근거, 테스트 결과, 문제 해결 과정이 있으면 완전히 다른 평가를 받습니다.

## 10-02 문제 해결 사례 쓰는 법 (STAR)

**S**ituation 상황, **T**ask 해야 할 일, **A**ction 한 일, **R**esult 결과(숫자). 원인을 어떻게 좁혔는지가 핵심입니다.

### 예시 1: 칼만 필터 상수

- S: 인터넷 예제의 칼만 상수(Q_bias 0.003, R 0.03)로 시뮬레이션하자 어떤 PID 게인으로도 2~4 초 안에 넘어짐.
- T: 제어기 문제인지 추정기 문제인지 분리해야 함.
- A: 센서를 참값으로 바꾸는 모드(SIM_IDEAL)를 만들어 비교. 제어기는 정상이고 추정 각도가 실제보다 작게 나오는 것을 확인. 원인은 "기운 채 가속하면 가속도계가 똑바로 서 있다고 읽는" 가짜 평형. 부팅 시 자이로 바이어스를 먼저 보정하고, 필터가 자이로를 더 믿도록 R 을 100 배, Q_bias 를 1/30 로 조정. 이 성질을 감시하는 단위 테스트 추가.
- R: 시뮬레이션 324 경우 중 통과 2 개에서 200 개로. (실제 로봇에서 확인한 결과를 이어서 적습니다.)

### 예시 2: EEPROM 저장 중 넘어짐 (설계 단계에서 예방)

- S: 파라미터 22 바이트를 EEPROM 에 쓰는 데 바이트당 3.3 ms, 합계 약 73 ms 소요.
- T: 제어 주기 5 ms 를 지키면서 저장해야 함 (SWR-07).
- A: 버퍼에 담아 두고 메인 루프마다 EEPE 비트를 확인해 한 바이트씩 쓰는 비차단 방식 구현. 값이 같으면 쓰지 않아 수명도 보호.
- R: 저장 중에도 제어 루프 지연 없음 (TC-07 통과).

### 예시 3: PWM 0 에서 펄스가 남는 문제 (데이터시트 검토로 예방)

- S: 모터 정지 명령에서도 출력이 완전히 0 이어야 함.
- T: 타이머 설정이 이를 보장하는지 확인.
- A: 데이터시트 검토 결과 Fast PWM 은 OCR = 0 이어도 매 주기 1 클럭 폭 펄스를 냄. 듀티 0 일 때 비교출력을 끊고 핀을 LOW 로 고정하도록 BSW 설계.
- R: 정지 시 핀 출력 0 V (오실로스코프 또는 멀티미터로 직접 측정해 수치를 적습니다).

위 세 사례는 이 과정에서 실제로 내린 설계 판단입니다. 본인이 겪은 문제로 바꾸거나 추가하면 더 강한 포트폴리오가 됩니다.

## 10-03 이력서 문구 예시

```
2륜 밸런싱 로봇 1인 개발 (HW, 기구, 펌웨어, 앱, 테스트)                  2026.xx ~ 2026.xx
- V 모델 기반 요구사항(SYS 9, SWR 10) 정의와 추적성 매트릭스 작성, 14 개 통합 테스트로 검증
- ATmega328P 레지스터 수준 펌웨어(BSW/DRV/ASW 3 계층, 11.5 KB) 설계, 5 ms 제어 주기
- 칼만 필터 + PID + 속도 보상 제어, PC 도립진자 시뮬레이터로 사전 검증해 게인 탐색 범위를 확정
- KiCad 2층 쉴드 PCB 설계 및 발주, Fusion 360 3D 프린팅 프레임 설계
- Android 블루투스 앱(조이스틱, PID 튜닝, 텔레메트리)과 체크섬 기반 통신 프로토콜 설계
```

수치와 동사로 씁니다. 숫자는 반드시 본인이 측정한 값으로 바꿉니다.

## 10-04 면접 예상 질문과 답변 포인트

| 질문 | 답변 포인트 |
|---|---|
| 칼만 필터를 왜 썼나요? 상보 필터와 차이는? | 둘 다 고주파는 자이로, 저주파는 가속도계를 씀. 칼만은 바이어스까지 추정하고 혼합 비율을 공분산으로 자동 조정. 이 로봇에서는 R 을 크게 두어 사실상 느린 상보 필터처럼 동작하게 만든 이유 (가짜 평형) |
| 제어 주기 5 ms 는 어떻게 정했나요? | 넘어지는 시간 상수 약 0.1 초보다 충분히 짧게, MPU6050 출력 200 Hz 와 맞춤, 연산 약 1 ms 로 여유 확인 |
| volatile 은 언제 쓰나요? | ISR 과 메인이 공유하는 변수. 최적화로 레지스터에 캐시되는 것 방지. 원자성은 보장하지 않으므로 32비트 틱은 ATOMIC_BLOCK |
| ISR 을 짧게 하는 이유는? | 다른 인터럽트 지연, 링버퍼에 넣고 처리는 메인에서 |
| I2C 에서 센서가 빠지면? | 모든 대기에 타임아웃, 3 회 연속 실패 시 모터 정지 후 1 초마다 재초기화 (TC-13) |
| 워치독은 어떻게 썼나요? | 250 ms, 메인 루프에서 리셋. IMU 재초기화 150 ms 를 고려해 시간 결정 |
| 적분 포화(windup)는? | Ki x integ 가 출력 한계를 넘지 않게 적분값 제한 |
| D 항을 오차 미분 대신 자이로로 쓴 이유는? | 목표 변경 시 미분 튐 방지, 수치 미분 잡음 없음 |
| 엔코더 없이 속도 제어는? | 출력의 저역통과 값을 속도 추정으로 사용, 한계와 개선안(엔코더 추가) 설명 |
| 계층 구조의 장점은 실제로 무엇이었나요? | ASW 가 MCU 를 모르므로 PC 에서 단위 테스트와 시뮬레이션 가능. 칼만 문제를 보드 없이 찾음 |
| 통신 프로토콜에 체크섬을 넣은 이유는? | 무선 잡음으로 깨진 명령이 모터 명령으로 해석되면 위험. 시작 문자 재동기화, 범위 검사, 오류 응답 |
| 요구사항 하나를 예로 들어 검증까지 설명해 보세요 | SYS-06 (45 도, 10 ms 정지) > balance 상태 머신 > sim 큰 충격 시나리오 > TC-08 |
| 가장 어려웠던 점은? | 10-02 사례 하나를 STAR 로 |
| 회로에서 HC-05 RXD 에 분압을 넣은 이유는? | 3.3 V 입력, 5 V 직결 시 손상 가능 |
| L298N 의 단점과 대안은? | 바이폴라라 약 2 V 강하와 발열, MOSFET 드라이버(TB6612FNG, DRV8833) 대안 |
| EEPROM 저장 데이터가 깨지면? | magic, version, CRC8, 범위 검사 후 기본값 |
| 다음 버전에서 바꾸고 싶은 것은? | 엔코더, 상태 공간(LQR) 제어, 배터리 전압에 따른 게인 보상, BLE |
