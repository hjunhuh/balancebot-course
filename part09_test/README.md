# Part 9. 밸런싱로봇 통합 TEST

V 모델의 오른쪽을 올라가는 단계입니다. HW, 펌웨어, 앱을 한꺼번에 붙이면 문제가 생겼을 때 원인이 어디인지 알 수 없습니다. 작은 단위부터 하나씩 붙이고, 각 단계마다 Part 4 요구사항을 판정 기준으로 씁니다.

## 9-01 통합 순서

| 단계 | 붙이는 것 | 확인할 것 | 테스트 |
|---|---|---|---|
| 1 | 쉴드 + Uno (모듈 없음) | 단락, 전압, 분압비 | 5-10 점검표 |
| 2 | + 펌웨어 | 부팅, LED, 텔레메트리 | TC-01, TC-02 |
| 3 | + MPU6050 | 각도 부호, 보정 | TC-03, TC-13 |
| 4 | + L298N, 모터 (바퀴 띄움) | 모터 방향, 데드존 | TC-04, TC-05, TC-08 |
| 5 | + HC-05, 앱 | 명령, 응답, 저장, 끊김 | TC-06, TC-07, TC-09, TC-14 |
| 6 | + 배터리, 기구 완성 | 저전압 | TC-10 |
| 7 | 바닥에 세움 | 밸런싱, 조종 | 9-04 튜닝 후 TC-11, TC-12 |

## 9-02 준비물

- 휴대폰에 "Serial Bluetooth Terminal" 류의 시리얼 터미널 앱 (Part 7 앱 이전 단계 확인용)
- 멀티미터
- 바퀴를 띄울 받침 (책, 상자)
- 넘어질 때 받을 손 또는 부드러운 매트
- 결과 기록용 표 (9-07 템플릿)

체크섬 계산이 번거로우면 아래 프레임을 그대로 복사해 보냅니다. 터미널 앱의 줄 끝 설정은 LF(`\n`) 로 둡니다.

| 목적 | 프레임 |
|---|---|
| 파라미터 요청 | `$G*47` |
| 모터 허용 | `$M,1*50` |
| 모터 정지 | `$M,0*51` |
| 저장 | `$S*53` |
| 조이스틱 중립 | `$D,0,0*44` |

## 9-03 테스트 케이스 명세

| ID | 요구사항 | 절차 | 기대 결과 |
|---|---|---|---|
| TC-01 | SYS-08, SWR-03 | 바퀴를 띄우고 로봇을 가만히 둔 채 전원 투입 | LED 가 약 1 초 빠르게 깜빡인 뒤 1 Hz 깜빡임 (WAIT_UPRIGHT). 보정 중 흔들면 빠른 깜빡임이 다시 1 초 이어짐 |
| TC-02 | SWR-01, SWR-08 | 터미널로 수신, 10 초간 줄 수 세기 | `#A,...` 줄이 약 100 개, 마지막 필드(상태)가 2 |
| TC-03 | SWR-02 | 로봇을 손으로 앞으로 약 20 도, 뒤로 약 20 도 기울임 | `#A` 각도 필드가 앞 약 +2000, 뒤 약 -2000. 반대면 `IMU_ANGLE_SIGN` 수정 |
| TC-04 | SYS-03 | 바퀴 띄우고 손으로 세워 WAIT 통과(LED 켜짐) 후 앞으로 살짝 기울임 | 두 바퀴 모두 로봇 앞쪽으로 회전. 반대인 쪽은 `MOTOR_x_INVERT` 수정 |
| TC-05 | SWR-04 | TC-04 상태에서 아주 조금씩 기울이며 바퀴가 돌기 시작하는 순간의 `#A` 출력 필드 관찰 | 출력 약 10 이내에서 바퀴가 돌기 시작. 너무 늦으면 `MOTOR_DEADBAND_PWM` 올림, 출력 0 근처에서 윙윙거리면 내림 |
| TC-06 | SWR-05 | `$G*47`, `$G*48`, `$Q*51`, `$P,-1,0,0*60` 전송 | 각각 `#K,...`, `#E,1`, `#E,4`, `#E,3` 수신 |
| TC-07 | SYS-05, SWR-06, 07 | `$P,3000,100,90*..` (앱 사용 권장) 후 `$S*53`, 전원 껐다 켬, `$G*47` | `#O,S` 와 `#K` 수신, 재부팅 후 `#K,3000,100,90,...` 유지. 저장 중에도 밸런싱이 끊기지 않음 |
| TC-08 | SYS-06 | 밸런싱 중(또는 바퀴 띄우고 BALANCE 상태) 로봇을 45 도 이상 기울임 | 즉시 모터 정지, 상태 4, LED 1 Hz. 다시 세우면 0.3 초 뒤 재개 |
| TC-09 | SYS-04 | 앱 조이스틱을 앞으로 민 상태에서 블루투스 연결을 강제로 끊음(앱 종료) | 0.5 초 이내 전진이 멈추고 제자리 밸런싱 |
| TC-10 | SYS-07 | 가변 전원 장치로 VIN 을 7.0 V 에서 6.4 V 로 낮춤 (가변 전원이 없으면 방전된 배터리 사용) | 6.6 V 아래로 2 초 지나면 상태 6, 모터 정지, LED 두 번 깜빡임 반복 |
| TC-11 | SYS-01, 02 | 평탄한 바닥에서 세우고 손을 뗌, 60 초 관찰 | 60 초 이상 서 있음, `#A` 각도 필드 ±200 (±2 도) 이내 |
| TC-12 | SYS-03 | 앱 조이스틱 전진, 후진, 좌회전, 우회전 각 3 초 | 해당 방향으로 움직이고 넘어지지 않음 |
| TC-13 | SYS-08, 09, SWR-10 | 동작 중 MPU6050 SDA 선을 뽑았다 다시 꽂음 | 뽑는 즉시 모터 정지, LED 100 ms 토글. 다시 꽂으면 1 초 안에 재보정 시작 |
| TC-14 | SYS-08 | 버튼을 한 번 누름, 다시 누름 | 첫 번째: 상태 5 (IDLE), 모터 정지, LED 꺼짐. 두 번째: 상태 2 로 복귀 |

TC-06 의 잘못된 프레임 체크섬은 의도한 값입니다. `$Q*51` 은 Q(0x51) 로 체크섬은 맞고 명령이 없으므로 `#E,4`, `$P,-1,0,0*60` 은 체크섬이 맞고 값이 범위 밖이라 `#E,3` 입니다.
