# Part 9. 밸런싱로봇 통합 TEST

V 모델의 오른쪽을 올라가는 단계입니다. HW, 펌웨어, 앱을 한꺼번에 붙이면 문제가 생겼을 때 원인이 어디인지 알 수 없습니다. 작은 단위부터 하나씩 붙이고, 각 단계마다 Part 4 요구사항을 판정 기준으로 씁니다.

## 9-01 통합 순서

| 단계 | 붙이는 것 | 확인할 것 | 테스트 |
|---|---|---|---|
| 1 | 쉴드 + Uno (모듈 없음) | 단락, 전압, 분압비 | 5-10 점검표 |
| 2 | + 펌웨어 | 부팅, LED, 텔레메트리 | TC-01, TC-02 |
| 3 | + MPU6050 | 각도 부호, 보정 | TC-03, TC-13 |
| 4 | + L298N, 모터 (바퀴 띄움) | 모터 방향, 데드존 | TC-04, TC-05, TC-08 |
| 5 | + HC-05, 앱 | 명령, 응답, 저장, 끊김 | TC-06, TC-07, TC-09, TC-14 |
| 6 | + 배터리, 기구 완성 | 저전압 | TC-10 |
| 7 | 바닥에 세움 | 밸런싱, 조종 | 9-04 튜닝 후 TC-11, TC-12 |
